# 表紙キャッシュでPDFとPNGページが消える問題

2026-10-19。本人のiPad実機報告を受けて修正。

## 原因と変更

CloudLibraryView.openは取得済みファイルが1つでもあればそれだけを閲覧一覧に使用し、初期形式も取得済みを優先していた。一覧の表紙としてPNGの1枚目だけがキャッシュされるため、PDF/PPTXの形式選択と残りPNGのページ操作が消えていた。端末固有ではなく、表紙しか取得していない端末で発生する。

CloudLibraryStore.readingFilesで、オンライン時は検証済みの資料詳細（同じID/版の全形式・全ページ）を使い、オフラインまたは明示localOnly時だけ取得済みに絞る。形式は返された一覧から既存のPDF→PNG→PPTX優先で選ぶ。既存の詳細キャッシュ・SHA256検証・版別保存とオフラインの取得済み限定を維持する。表紙キャッシュや保存資料の削除は不要。

## 検証

- iPad Pro 11インチ M5 / iOS26.5 Simulatorで69 XCTest、失敗0。

- 画面操作：本棚の表紙表示後にPDFが開く。PDF/PNG/PPTXメニューを確認。PNGへ切替、タップで全画面、スワイプで2/8、次ボタンで3/8へ移動。PDFへ戻す操作も確認。画像はoutputs/reader-cover-cache-fix。
- Mira指定署名build・codesign検証合格。実機更新・起動結果は以下へ追記する。

AWS/API/整理データ形式は変更しない。全資料の全ページとPDF/PPTXの全形式手動確認を実施したとは扱わない。
